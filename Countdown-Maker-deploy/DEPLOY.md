# 정적 사이트 배포

`Countdown-Maker-deploy.zip`은 빌드가 끝난 배포본입니다. 압축을 풀면 최상위에 `index.html`, `app.js`, `style.css`, `fonts/`가 있습니다. **이 파일들을 폴더 구조 그대로 웹사이트 루트에 업로드**하세요. 빌드 명령, Node.js 서버, API 키, 데이터베이스는 필요하지 않습니다.

1. ZIP 압축을 해제합니다.
2. 정적 파일 호스팅의 업로드/배포 기능 또는 웹서버 문서 루트에 전체 내용을 올립니다.
3. HTTPS 주소로 접속합니다. 일반 HTTP에서는 영상 인코더 등 일부 브라우저 기능이 제한될 수 있습니다.
4. 글꼴 탭의 **레코체**를 선택하고 미리보기와 내보내기를 확인합니다.

`fonts/Recipekorea.otf`를 포함한 모든 파일을 업로드해야 합니다. 사용자가 제공한 OTF 원본을 수정 없이 포함했고, 실제 제공된 단일 굵기만 사용합니다. 30,000kbps 기본 목표 및 모든 프레임 독립 저장 설정도 포함합니다.

## 글꼴 배포 조건

레시피코리아 공식 배포 안내에는 폰트 파일 재배포 제한이 있습니다. 웹폰트 내장은 방문자에게 폰트 파일을 제공하므로, **공개 호스팅 전에 이 파일에 적용되는 웹 배포 허락을 권리자에게 확인**하세요. 이 패키지를 받았다는 사실 자체가 재배포 허락을 의미하지 않습니다.

공식 안내: https://recipekorea.com/bbs/board.php?bo_table=ld_0308&wr_id=3648

## 저장 데이터

폰트·프리셋은 방문자의 브라우저 IndexedDB에 저장됩니다. 기존 Sites 주소와 새 배포 주소는 서로 다른 저장 공간을 사용합니다. 기존 프리셋은 JSON으로 백업한 뒤 새 주소에서 가져오세요. 기본 레코체는 새 주소에서도 별도 등록 없이 선택할 수 있습니다.

소스 수정 시 전체 소스 ZIP에서 `npm ci`, `npm run build`를 실행하고 `dist/` 내용물을 다시 배포하세요. `file://` 더블클릭 대신 HTTPS 또는 로컬 HTTP 서버로 실행하세요.
