비트레이트 개선 검증

목표 비트레이트 1,000~100,000kbps 직접 입력, 기본 30,000kbps/VBR/모든 프레임 독립 저장을 제공합니다. 제공된 레코체 TTF로 1080p/60FPS/91프레임을 출력해 Chrome 22,534kbps, Edge 22,524kbps를 확인했습니다. 91프레임 모두 독립 키프레임이며 실제 디코딩도 통과했습니다. 출력 완료 화면에 실제 영상 비트레이트를 표시합니다.

비트레이트 단위 2개와 브라우저 통합 2개를 추가 통과했고, 기존 엔진 및 Chrome/Edge 테스트도 다시 통과했습니다. 실제 비트레이트는 장면과 인코더에 따라 달라지며 목표값이나 최소 10,000kbps를 보장하지 않습니다.

실제 파일로 확인했습니다

Chrome·Edge에서 1080p MP4 60FPS 31프레임, WebM 30FPS 16프레임을 생성하고 실제 디코딩 개수까지 확인했습니다. PNG ZIP은 프레임 수, 투명·반투명 알파, 동일 설정의 미리보기 렌더러와 픽셀 일치를 확인했습니다.

TTF·OTF 등록과 재로딩, 프리셋 관리, 출력 취소, 모바일 폭 390px에서의 화면 구성, 인코더 미지원 시 PNG 전환, 오프라인 로딩을 검증했습니다.

남은 검증 범위

실제 iPhone Safari·Android Chrome 및 파일 앱 저장 동작은 검증하지 못했습니다. 모바일 화면 에뮬레이션은 실제 기기 검증을 대체하지 않습니다. 레시피코리아체 V1.1 Light/Medium/Bold 각각의 파일과 WOFF/WOFF2 실파일 테스트, CapCut·Resolve 앱 안에서의 가져오기도 미실시입니다.

MP4·WebM은 브라우저 인코더 지원 여부를 검사해 활성화하며, PNG ZIP은 인코더 없이 생성합니다. 앱의 영상 검증은 파일 내부 프레임 패킷·타임스탬프 검사이며 OCR 검사는 아닙니다.
